1. 功能重复分析

1.1 命名空间冲突

模块 现有项目 Vibe-Trading 状态
src/agent/skills/ 执行型策略 (YAML) - 保留现有
src/skills/ - 文档库 (SKILL.md) 已迁移到 src/skills_library/
src/memory/ - 记忆系统 无冲突
src/goal/ - 目标追踪 无冲突
src/hypotheses/ - 假设注册表 无冲突

1.2 策略功能对比

功能 现有项目 Vibe-Trading 重复程度
Trading Skills src/agent/skills/ - 运行时策略执行 src/skills_library/ - 文档查询 不重复
Scanner src/services/market_scanner.py agent/skills/market-scan/ 部分重复，保留两者
Gold Digger src/services/gold_digger.py agent/skills/value-fishing/ 部分重复，保留两者
Backtest src/services/backtest_service.py agent/skills/backtest-diagnose/ 部分重复，保留两者
Strategy YAML strategies/*.yaml agent/skills/ 不重复（格式不同）

3. 使用场景对比

3.1 现有 src/agent/skills/
  • 用途：执行交易策略
  • 使用方式：通过 Agent 自动选择并执行
  • 示例：dragon_head.yaml (龙头策略)
3.2 Vibe-Trading src/skills_library/
  • 用途：查询分析方法论
  • 使用方式：CLI 查询或 LLM 上下文注入
  • 示例：technical-basic/ (技术指标文档)

对比示例

# 查询现有策略（执行）
python main.py --skills dragon_head  # 使用策略

# 查询 Vibe-Trading 技能（学习）
python main.py --skill-show technical-basic  # 查看文档

5. CLI 命令总览

5.1 现有命令（不变）

python main.py --gold-digger         # 沙里淘金
python main.py --skills <skill>       # 使用策略

5.2 新增命令

命令 功能
--memory-add "Title" --memory-body "Content" 添加记忆条目
--memory-search "query" 搜索记忆
--goal-create SYMBOL --goal-title "Title" 创建目标
--goal-list 列出目标
--goal-check 检查目标状态
--hypothesis-create "Title" --hypothesis-thesis "Theory" 创建假设

--skill-show technical-basic 查看技能详情
--watchlist-note CODE --note-title "Title" 给自选股添加笔记
--sync-watchlist-to-memory 同步自选股到记忆

7. 注意事项

7.1 命名空间

  • src/agent/skills/：保留现有执行型策略系统
  • src/skills_library/：Vibe-Trading 文档库（已重命名避免冲突）

7.2 功能边界

类型 模块
执行型策略 strategies/*.yaml + src/agent/skills/
学习型策略 src/skills_library/
目标追踪 src/goal/
假设验证 src/hypotheses/
记忆存储 src/memory/

7.3 扩展建议

如需添加新的分析技能：

  1. 执行型：创建 strategies/my_strategy.yaml
  2. 学习型：创建 src/skills_library/my-skill/SKILL.md
