Unified Skills Registry

统一策略注册表 - 整合现有执行型策略与 Vibe-Trading 学习型技能

Date: 2026-05-27

1. 背景与目标

项目原本有两套策略/技能系统：

  • 现有策略 (strategies/*.yaml): 执行型策略，Agent 调用工具执行
  • Vibe-Trading (skills_library/*/SKILL.md): 学习型技能，提供分析方法

Unified Skills Registry 将两者整合为统一的注册表，支持协同工作。

2. 两种策略对比

特性 Execution Skills Learning Skills
来源 strategies/*.yaml skills_library/*/SKILL.md
格式 YAML Markdown + YAML frontmatter
类型 Execution Learning
用途 Agent 执行策略，调用工具 提供分析方法，供 LLM 参考
关键字段 instructions, required_tools, aliases, priority description, category, body (详细说明)
示例 dragon_head.yaml (龙头策略) technical-basic/SKILL.md (技术指标)

4. 代码实现

4.1 核心类

src/unified_skills/registry.py

class SkillType(Enum):
    EXECUTION = "execution"   # 现有策略
    LEARNING = "learning"     # Vibe-Trading

@dataclass
class UnifiedSkill:
    name: str
    display_name: str
    description: str
    skill_type: SkillType
    category: str
    
    # Execution 特有
    instructions: str
    required_tools: List[str]
    aliases: List[str]
    default_priority: int
    
    # Learning 特有
    body: str
    metadata: Dict

class UnifiedSkillRegistry:
    def _load_execution_skills(self): ...  # 加载 strategies/*.yaml
    def _load_learning_skills(self): ...   # 加载 skills_library/*
    def get(self, name): ...
    def search(self, query): ...

4.2 使用示例

# 获取统一注册表
from src.unified_skills import get_unified_registry, SkillType

registry = get_unified_registry()

# 列出所有执行型策略
exec_skills = registry.list_all(SkillType.EXECUTION)

# 列出所有学习型技能
learn_skills = registry.list_all(SkillType.LEARNING)

# 按名称或别名获取
skill = registry.get("dragon_head")  # 或 "龙头"

# 搜索
results = registry.search("momentum")

7. 集成优势

场景 原有方案 统一注册表
策略查询 需要分别查询两个系统 一个命令查询所有
Agent 使用 只能使用 Execution 策略 可同时参考 Learning 技能
策略发现 容易遗漏某类策略 统一视图，一目了然
扩展性 两套系统各自维护 统一接口，便于扩展

8. 后续扩展

  • Agent 集成：让 Agent 可以同时使用 Execution 策略和 Learning 技能
  • 策略推荐：根据市场状态自动推荐相关策略
  • 策略组合：支持多个 Execution 策略组合使用
  • 用户自定义：支持用户添加自定义策略到统一注册表
